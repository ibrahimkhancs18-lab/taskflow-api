# TaskFlow API

A task management API built with ASP.NET Core (.NET 10) and PostgreSQL,
used as a hands-on project to learn the full build, ship, and deploy flow:
Docker, Jenkins CI/CD, and monitoring on a Linux server.

## Status
Work in progress. Currently at v0.1 (server setup and repository).

## Roadmap
- v0.1 Server setup, repository, first API
- v0.2 Docker and Docker Compose
- v0.3 Jenkins CI
- v0.4 Image registry
- v0.5 Automated deploy
